# タスク: EC ログ分類

EC サイトのアプリケーション / インフラログ 1 行（または 1 イベント）を、
あらかじめ定義したラベルのいずれか 1 つに分類する。

- タスク定義（評価データ・ラベル）: [`task.toml`](task.toml)
- LLM 用プロンプト: [`prompt.md`](prompt.md)（Jev / Laya には同じ指示文・ラベル定義を `choice` 質問で渡す）
- データ形式: JSONL（1 行 1 レコード）

```json
{"id": "s001", "text": "<ログ本文>", "label": "payment"}
```

## データセット

| パス | 内容 | コミット |
| --- | --- | --- |
| `data/samples/` | 動作確認用の合成サンプル | する |
| `data/raw/` | 実ログ・公開データセットの生データ | しない |
| `data/processed/` | 前処理・ラベル付け済みデータ | しない |

## 評価指標

- Accuracy / Macro-F1 / クラス別 Precision・Recall
- ラベル外出力率（`invalid_rate`）・エラー率（`error_rate`）
- レイテンシ（1 件あたりの p50 / p95）
- コスト（API のトークン数・料金）
